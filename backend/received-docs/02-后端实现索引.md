# 后端实现索引

前端界面和业务 DTO 保持由前端负责。此处只帮助接收方找到源码。

| 要看什么 | 文件 |
|---|---|
| HTTP、静态页面、WebSocket 路由 | `server/app.py`、`server/realtime_console.py` |
| LLM 调度职责、证据短选择码、容错继续 | `server/console_coordinator.py` |
| 店名、角色名、地域风格、每家系统提示词 | `server/console_persona.py` |
| 商户 CSV 读取和候选资料 | `server/console_data.py` |
| 评论线索、数字与来源校验 | `server/console_reviews.py`、`server/console_evidence.py` |
| 同差评同问题去重、已听攻击点 | `server/console_attack_memory.py` |
| 偏好更新、实际已听文本、打断与预生成 | `server/console_preferences.py`、`server/console_playback.py`、`server/realtime_console.py` |
| 模型调用、服务端识别、TTS 客户端 | `server/providers/` |
| 独立 CosyVoice GPU 服务 | `scripts/cosyvoice_service.py` |
| 前端采集、播放时钟、清队列的已运行参考 | `web/console.js`、`web/console-audio-worklet.js`、`web/console-playback.js` |
| 当前提示词文本快照 | `config/agent-prompts.snapshot.json` |
| 生成提示词快照 | `scripts/export_agent_prompts.py`，实际运行时完整输入/提示词可在控制台节点查看 |

当前人格规则版本为 persona-v11。Agent 只有调度器与各餐厅；VAD/STT/TTS、数据读取、证据检查、攻击点记忆都是普通组件。

音频是 PCM 实时流，正式文本每轮一次完整对象；音频与文本按 epoch/turnId/segmentId 关联。调度仅选行为、对象和资料，不代写台词。引用失败过滤、数量不设 4 条硬上限，资料仍不足时重选/降级继续；同评论同问题在全场共享记忆中避免反复攻击。接收方最终业务字段尚待前端给出结构后适配。

源码里的旧 REST/LiveKit Demo 仍保留，不表示产品必须使用旧人物、旧数据 DTO 或旧页面。新实时接入优先看 `/api/realtime` 和 `console_*` 文件。
