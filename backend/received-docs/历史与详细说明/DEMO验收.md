# 本地 Demo 验收记录

验收日期：2026-10-17。项目位于 `F:\吃啥`。

## 打开与启动

演示地址：http://127.0.0.1:8770

本次已启动本地服务，浏览器保留最终推荐画面。服务关闭后，双击 `start_demo.cmd`，或在 PowerShell 中执行 `./start_windows.ps1`。启动脚本使用项目自己的 `.venv`，无需手工激活环境。

## 演示顺序

1. 点击“重新开始”，恢复两家讨论、一家候场。
2. 点击“预算 150”，观察预算和朋友聚餐偏好。
3. 点击“花生过敏”，可在讨论中追加这条要求。
4. 点击“换一家”，蓉姐川味离场，Pierre 小馆加入，已有偏好保留。
5. 点击“原评 · 4行”，展示丁香小鲜来源工作表、行号与原文高亮。
6. 关闭原评，点击“帮我决定”，丁香小鲜出现“今晚首选”。

本地朗读默认关闭。点击“朗读：关”可以开启浏览器系统朗读；其可用性取决于浏览器和已安装音色。文字演示不依赖语音服务。
